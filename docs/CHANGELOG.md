# 변경 묶음과 검토 순서

이 변경은 Lucel 작성자 정보로 다음 단위로 나눠 커밋합니다.

## 1. 관리자 검수 제거·상인 게시·안정화

- 관리자 API 14개와 검수·승인·반려 전용 코드 제거
- 상인 가게 QR 권한 확인과 입력·첨부 파일 검증
- 콘텐츠 생성과 게시 분리: 상인이 게시 버튼을 누른 요청만 게시
- 생성·게시의 DB 실행 권한 선점과 내부 워커 복구
- 촬영 진행 상태를 덮어쓰지 않는 초안 병합
- 중복 활성 생성 작업 제한, 영상 유료 호출 전 작업 확보
- 실제 게시 기록만 게시 완료로 집계하고 사진·영상 보관함 조회 분리

## 2. AWS S3 저장소 호환 계층

- Supabase 기본 쓰기 유지, 환경 설정으로 S3 새 쓰기 활성화
- 기존 uploads 참조와 새 s3:bucket 참조의 동시 읽기
- 원본·생성 이미지·영상·썸네일·검수·미리보기·Instagram URL 연동
- 비공개 서명 URL, 덮어쓰기 방지 조건부 업로드, 객체 존재 확인
- 허용 버킷 제한과 과거 버킷 읽기를 통한 전환·롤백 지원

## 3. 보안 의존성 갱신

- Next.js 및 eslint-config-next 16.4.3 고정
- 기존 버전 범위의 전이 의존성 보안 패치
- 운영 의존성 취약점 0개 확인, 개발 도구 잔여 사항은 OPERATIONS.md에 기록

## 4. 이전 도구·SQL·AWS 인프라

- 기본 읽기 전용 목록, 명시적 --apply 복사·전환·롤백 도구
- 파일 크기·SHA-256·MIME 검증과 원본 보존
- 다섯 참조의 원자적 전환 RPC와 실제 PostgreSQL 엔진 테스트
- 비공개 S3·암호화·버전 관리·HTTPS·IAM·CORS CloudFormation 정의
- 실제 DB·AWS 배포·파일 이전은 실행하지 않음

## 전시 화면 명세 후속 반영

- 기존 QR API와 분리한 전시 user_id=1 어댑터와 기본 비활성화 설정
- 정보 템플릿 저장·복사, 메뉴 최대 3개, 외부 콘셉트/장면 계약
- 선택적 대본 선행 생성과 편집 자막을 그대로 사용하는 WAV TTS 어댑터
- SC-07 일괄 재료 업로드·검증·멱등 생성·진행 단계·재시도
- 9:16 무음/내레이션 릴스와 이미지 썸네일, 공통 카드뉴스 렌더러
- 최근 4건 조회·형식/게시 상태 필터·페이징·빈 목록 구분
- 상세 캡션 수정·게시 잠금·현재 제작의 게시 권한·보관함 숨김 삭제
- 전시 원본/작업 스냅샷의 AWS 이전 참조와 전체 검증 선행 보호
- 실제 콘셉트별 최종 디자인과 TTS 공급자 설정은 담당자 결과/환경을 받아 연결
