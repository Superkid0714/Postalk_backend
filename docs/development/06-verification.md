# 6. 테스트·운영 체크리스트

## 배포 직후

- `GET /api/health`가 `status: ok`인지 확인
- `GET /api/health/ready`에서 `database`, `storage`가 모두 `ok`인지 확인
- 게스트 작업 공간 생성 후 새로고침해도 같은 작업 공간이 열리는지 확인
- 사진 6장 카드뉴스와 영상 4개 릴스를 각각 1건씩 생성

## 생성 결과

- 카드뉴스 PNG 3장이 보관함에 표시되는지 확인
- 릴스 MP4와 썸네일이 표시되는지 확인
- 진행 화면에서 완료·실패 상태가 구분되는지 확인
- 게스트 화면에 Instagram 게시 버튼이 보이지 않는지 확인

## 상인 게시

- 별도 상인 테스트 계정에서만 Instagram 게시 리허설
- 게시 전 캡션과 결과 파일을 확인
- 실제 행사 계정에는 필요 이상으로 반복 게시하지 않음

## 보안

- GitHub에 `.env`, 토큰, 개인 파일이 없는지 확인
- 프론트에는 anon/publishable 키 외의 서버 비밀값을 넣지 않음
- 로그와 오류 화면에 서명 URL·내부 키를 출력하지 않음
