# 1. 서비스 흐름

POSTALK는 가게 사진이나 영상으로 카드뉴스·릴스를 만들고 결과를 보관하는 서비스입니다. Instagram 게시가 필요한 경우에는 상인 권한으로만 직접 게시합니다.

```text
접속
→ 게스트 작업 공간 또는 상인 QR 인증
→ 사진·영상 업로드
→ 카드뉴스 또는 릴스 제작 세션
→ AI 생성
→ 결과 확인·보관
→ 상인 선택 시 Instagram 게시
```

| 구분 | 카드뉴스 | 릴스 |
| --- | --- | --- |
| 입력 | 사진 6장 | 영상 4개 |
| 선택값 | `minimal`, `christmas` | `simple`, `christmas` |
| 결과 | 1080×1350 PNG 3장 | 1080×1920 MP4와 썸네일 |
| 게시 | 상인 QR 권한 필요 | 상인 QR 권한 필요 |

게스트는 콘텐츠 생성과 보관함 조회를 할 수 있지만 Instagram 게시와 성과 조회는 할 수 없습니다.
